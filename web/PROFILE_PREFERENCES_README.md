# 알레르기 표시 및 사용자 정보 기억하기

## 화면

알레르기 선택창은 기존 입력창과 같은 폰트 계열·14px·500 굵기를 사용한다.
안내문은 짧은 한 문장으로 표시한다. 학교명·날짜·빈도 등을 펼치는 UI는 제거하고
원본 추정 JSON과 NEIS 출처는 그대로 보존한다.

기존 추천 계산 전에 알레르기 제외를 계속 적용한다. 남은 식단을 기존 알고리즘으로
정렬한 뒤 제외 식단을 순위 없는 연회색 카드로 붙인다. 제외 카드에는 성분별 간단한
라벨과 영양정보가 보이지만 클릭·키보드 상세보기·추천 순위가 없다.
날짜·식당별 전체 카드 수는 필터 전후 같다. 모든 메뉴가 제외돼도 제외 카드들은 남는다.
남은 메뉴도 원재료 확인 필요 상태다.

## 저장과 동의

- 기본값은 저장 안 함. 사용자가 `내 정보 기억하기`를 체크한 뒤에만 기록한다.
- localStorage 키: `hyu-menu-guide.profile.v1`
- 저장 항목: 성별, 나이, 키, 체중, 활동수준, 하루 식사 횟수, 추천 목표, 목표 감량 체중,
  알레르기 선택 번호. 저장 형식 version 1과 consent true를 함께 기록한다.
- 입력·선택 변경 시 갱신하며 전체 해제로 알레르기를 지운 경우도 저장에 반영한다.
- 접속 시 유효한 저장 정보와 동의가 있는 경우만 자동 입력한다. 추천 계산 버튼의 기존 동작은 유지한다.
- 체크 해제 또는 `저장된 정보 삭제` 시 이 서비스의 키만 제거한다. 다른 사이트/기능의 키를 지우지 않는다.
- 삭제 후 현재 입력은 세션 동안 유지되며 다음 새로고침에서는 복원되지 않는다.
- 회원가입·서버 전송 없이 동일 브라우저·동일 사이트 주소(origin)에서만 유지된다.
  localhost 포트가 바뀌거나 GitHub Pages로 이동하면 다른 저장 공간이다.
- 저장 차단·공간 부족은 화면 상태로 알린다. 저장을 못 해도 추천 기능은 계속 작동한다.
- 공용 기기 저장 주의 안내와 삭제 기능을 제공한다.

## 변경 파일

web/index.html, web/modern.css, web/allergy-ui.js,
web/profile-storage.js, web/profile-storage.test.cjs, 이 설명서.
web/allergy-data.json·allergy-filter.js·personal-score.js 등 판정 및 계산 모듈은 변경하지 않았다.

## 검증

`node --test web/recommendation.test.cjs web/allergy-filter.test.cjs web/profile-storage.test.cjs`

15개 테스트 통과. 기존 7모드·알레르기 판정 결과 회귀 검사 및 동의/삭제/잘못된 저장 정보 검사.
실제 Chrome 자동검증에서 다음을 확인했다.

- PC 1440px/모바일 390px: 19종 선택·해제·전체 카드 수 유지·제외 카드 하단 배치.
- 제외 카드 회색 배경, 클릭 핸들러 없음, tabindex 없음, 순위 없음.
- 상세 NEIS 패널 없음. 기존 입력창과 선택창 폰트 계열/크기/굵기 일치.
- 동의 없이 입력과 알레르기를 변경해도 localStorage 기록 없음.
- 동의 후 입력 변경·새로고침·Chrome 재실행 후 기본정보/식사 횟수/목표/감량값/알레르기 복원.
- 저장 삭제 및 동의 해제 후 기록 없음, 재접속 시 복원 안 됨, 다른 localStorage 키 유지.
- localStorage 사용 차단 시 저장 UI만 중지하고 기존 메뉴 정상 표시.
- 7개 목표 계산과 카드 렌더링에서 JavaScript 오류·추가 POST 요청·가로 넘침 없음.
