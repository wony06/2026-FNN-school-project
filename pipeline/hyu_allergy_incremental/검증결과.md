통합 보류는 사용자 확인한 2개만 해제하여 50개가 남았습니다. 10/26~11/2의 번호 미확인 표시는 10/28 생활과학대학 치킨너겟버펄로볼 1개입니다. 다른 미확인 부분은 상태와 원본 근거를 보존합니다.

## 자동 갱신

새 메뉴 수집, 웹 데이터 생성 및 별도 export 명령은 같은 sync_allergy_data 함수를 호출합니다. 신규/원문 변경은 별도로 분석하고, 영양 데이터만 바뀐 경우에는 알레르기 근거를 변경하지 않고 출처 해시를 갱신합니다. 배포 전 검증도 메뉴-알레르기 키 누락을 검사합니다.

## 보존 및 검증

- 기존 추천 알고리즘, 식품교환단위 및 영양 계산식은 변경하지 않았습니다.

- Node 회귀 테스트, Python 원문 분리·보류 정책 테스트, PC/모바일 브라우저 검증을 수행했습니다. 선택/미선택, 제외 카드 무순위, 새 메뉴 번호 표시, 날짜 선택 범위와 과거 데이터 보존을 검사합니다.
