## 현재 로직을 쉽게 설명하면

식판을 음식별로 나누고, 음식을 재료별로 나눈 뒤, 각 재료를 6개 식품군에 배정해서 합산합니다. 완성 음식의 전체 단백질·탄수화물을 한꺼번에 교환단위로 환산하는 방식이 아닙니다.

1. 메뉴의 &·* 등 복합 표기를 분리하고 기존 추정 중량을 적용합니다. 신소재관은 한양플라자 실측 제공량 규칙 대신 신소재관 항목의 기존 추정 중량을 씁니다. exchange_weight_g가 있으면 그 중량이 우선합니다.
2. 지정 제외 항목과 개별 예외를 처리합니다. 우동국·미소국·케찹·간장·초장 등은 제외되고, 돈까스소스·브라운소스·쌈장도 별도 제외합니다. 제외는 실제 교환단위가 0이라는 뜻이 아닙니다.
3. 별칭 및 조합 예외로 이름을 정리합니다. 예: 차돌된장찌개→차돌박이된장찌개, 제육볶음→돼지고기볶음(고추장, 야채).
4. 일반 검색은 custom_exchange_recipes → external_exchange_recipes → MenuGen → recipe_db → DB104 직접검색 순입니다. 특수 음식은 이 순서 전에 개별 처리됩니다. 파일 상단 설명은 MenuGen부터라고 되어 있지만 현재 함수 본문은 사용자 레시피와 외부 레시피가 먼저입니다.
5. 까스/가스, 일부 동의어·수식어·괄호 변형을 처리합니다. 최종 실패하면 승인된 접두어를 제거하고 다시 찾습니다. 모든 유사한 이름을 자동 연결하는 방식은 아닙니다. MenuGen 기본형에 괄호 변형이 여러 개면 돼지고기·소고기 순으로 대표를 고르는 규칙도 있습니다.
6. 표준 레시피의 각 재료량에 “해당 메뉴 제공량÷DB 기준중량”을 곱합니다. 예: 기준 200g 레시피를 300g 제공했다면 재료량을 각각 1.5배로 계산합니다. 조리 후 수율·증발량은 일반적으로 보정되지 않습니다.
7. 각 재료의 DB104 100g당 영양소×재료 중량÷100을 구하고, 아래 기준으로 교환단위를 환산해 식판 전체를 합산합니다.

|식품군|현재 코드의 계산식|
|---|---|
|곡류군|그 군 재료의 탄수화물 g÷23|
|어육류군|그 군 재료의 단백질 g÷8|
|채소군|그 군 재료의 탄수화물 g÷3|
|지방군|그 군 재료의 지방 g÷5|
|우유군|그 군 재료의 탄수화물 g÷10|
|과일군|그 군 재료의 탄수화물 g÷12|

이 표는 현재 코드의 구현 설명입니다. 예: 쌀·면은 곡류군, 고기·달걀·두부는 어육류군, 채소·버섯·해조류는 채소군, 기름·견과류는 지방군입니다. 마요네즈는 예외적으로 지방군에 배정합니다.

## 매칭을 마무리할 때 주의할 실제 코드 특성

- 영양성분 계산은 food_db·가공식품 DB와 수동 재구성값도 사용하므로 영양소가 있어도 교환단위는 미매칭일 수 있습니다. 식품교환단위는 기본적으로 재료 분해가 필요합니다.
- 조미료류·당류·음료류·주류·조리가공식품류 등은 FOOD_GROUP_MAP에서 계산 군이 없습니다. 칠리소스처럼 DB에 있어도 계산할 재료가 없으면 미매칭으로 남습니다. 단순히 이름을 추가하는 것과 계산을 완성하는 것은 다릅니다.
- 다만 망고 음료·매실청처럼 DB마다 식품군 분류가 달라질 수 있으므로 “모든 음료가 제외된다”로 일반화하면 안 됩니다. 실제 선택된 레코드의 분류를 확인해야 합니다.
- 재료 중 하나만 계산돼도 음식 전체가 matched=True가 될 수 있습니다. 레시피 내부 unresolved_ingredients는 음식 단위 unmatched 목록과 별개입니다. 따라서 미매칭 0건이 재료 100% 반영을 의미하지 않습니다. external 경로는 재료 환산 실패를 unresolved에 추가하지 않는 한계도 있습니다.
- 원재료 직접 매칭은 하나의 식품군으로만 환산합니다. 해시브라운을 감자군으로 연결하면 탄수화물 기반 곡류군만 계산하며 튀김 지방을 별도 지방군으로 자동 분해하지 않습니다. 어육류도 단백질 기준 단일 군으로 계산하며 저·중·고지방 분류를 별도 기록하지 않습니다.
- DB104 영양소가 숫자로 읽히지 않으면 코드에서 0으로 처리됩니다. 누락값과 실제 0을 구분하는 추가 점검이 필요합니다.
- 설탕꽈배기는 현재 200g이며 weight_note가 “국/탕류 사이드”로 기록되어 있습니다. 이름에 탕이 포함된 결과인지 중량 규칙을 확인해야 하며, 매칭 전에 실제 1개 중량을 확인하는 편이 좋습니다.
