# 팀원 전달용 식품교환단위 수정 묶음

## 작업 원칙
사용자 요청(2026-10-07): 메뉴 미매칭 수정은 이 묶음에 누적합니다. 사용자가 웹사이트 반영을 명시적으로 요청할 때 한 번에 반영합니다. 그 전에는 web/site_data.json, 웹사이트.html 등의 실행 데이터를 추가로 변경하지 않습니다.

## 확정된 수정 1건
- 대상: 2026-08-24 신소재공학관(204), 일품, 새우튀김카레라이스 식단의 바질크림떡볶이.
- 기본: recipe_db의 크림치즈떡볶이(seq463).
- 모짜렐라치즈30g 전량 제외. 바질도 전량 제외하며 이전 0.1g 추정은 철회.
- 우유·생크림·버터·파슬리 등 나머지 레시피 재료 유지. 제공량은 기존 추정40g.

## 전달 파일 사용법
1. custom_exchange_recipes_patch.json: 이름을 키로 프로젝트의 custom_exchange_recipes.json에 추가하거나 교체합니다. 전체 기존 파일을 덮어쓰지 않습니다.
2. manual_exchange_overrides_patch.json: 날짜·식당·구분·메인메뉴 4개 키로 기존 manual_exchange_overrides.json의 entries에 병합합니다. 해당 식단 전체의 교환단위 결과이므로 팀원 쪽에 같은 식단의 다른 수정이 있으면 그대로 덮어쓰지 않고 재계산합니다.
3. 변경내역.json: 원래 값, 음식별 새 교환단위, 최종 식단 값과 레시피를 함께 확인하는 검토 기록입니다.

기존 프로젝트의 Python 매칭 함수는 custom_exchange_recipes.json을 우선 조회하며, 내보내기에서는 manual_exchange_overrides.json을 보존합니다. 병합 후 기존 파이프라인으로 데이터를 갱신합니다. 이 묶음 자체는 배포하거나 웹사이트를 자동 갱신하지 않습니다.

## 현재 반영 상태
이 원칙을 정하기 전에 바질크림떡볶이 수정은 이미 작업 웹사이트에 반영되었습니다. 현재 화면을 되돌리지는 않았습니다. 이후 수정부터는 이 폴더에만 누적하고 사용자 요청 시 일괄 반영합니다.
