# 야채춘권 추정 매칭 완료

게살·치즈 제외. 사용자 승인 추정값 적용, 웹사이트 미반영.

1인분: 춘권피2.75장=37.8125g, 파프리카15g, 흡수된 콩기름5g, 핫소스7.5mL≈7.5g, 소금0.25g, 후추0.025g. 재료합계65.5875g이며 조리수율 미보정.

레시피 1인분 교환단위: {"grain":0.9535326086956522,"meat":0,"veg":0.3206666666666667,"fat":0.9995999999999998,"dairy":0,"fruit":0}

기존 식판의40g 환산: {"grain":0.5815331328046668,"meat":0,"veg":0.195565720094022,"fat":0.6096283590623212,"dairy":0,"fruit":0}

춘권피 근거: [CT Food 제품자료](https://ctfood.se/spring-roll-pastry-215x215mm-20x550g-40pcs-spring-home/?language=en). 실제 급식 제품이 아닌 대체제품. 파프리카량·흡수유량·양념량은 계산 가정이며 사진 실측값 아님. 기름은 튀김통에 넣는75mL 전량을 가산하지 않고 흡수유5g만 사용.

팀원 적용: exchange_ingredient_supplements_patch.json의 보조 레코드를 DB104_BY_NAME 조회에 제공한 뒤 custom_exchange_recipes_patch.json을 이름 기준 병합. 간단한 기존 파이프라인 적용에서는 db104_raw_ingredients.json 배열에 보조 레코드를 이름 기준으로 추가할 수 있으나 국가표준식품성분표 원본 항목과 구분해야 함. 이것은 DB104 공식 자료가 아님. manual_exchange_overrides_patch.json은 식단 키 기준 병합. 다른 수정이 있으면 식단 전체 값을 덮어쓰지 말고 재계산.

야채춘권: 사용자 첨부 4인분 게살야채춘권에서 게살1.5컵·피자치즈100g 전량 제외. 1인분=1/4로 유지하여 춘권피2.75장, 핫소스7.5mL, 파프리카·소금·후추 소량. 사용자가 추정 계산을 승인함. 춘권피는 실제 제품 미확인으로 CT Food Spring Home 215mm 550g/40장 제품자료 대체: 1장13.75g, 1인분37.8125g, 100g당 탄수화물58g. 파프리카는 4인분 총60g(각 색20g) 가정으로 1인분15g; 빨강5g·노랑5g은 DB 빨간 피망10g으로, 초록5g은 초록 피망으로 연결. 튀김용 식용유는 전체300mL 중 실제 흡수유만 1인분5g(전체20g)으로 가정하고 콩기름 성분 대체; 흡수유3~7g 민감도도 기록. 핫소스는 밀도1g/mL로7.5g, 소금0.25g·후추0.025g 가정하고 조미료류 제외규칙 유지. 기준총65.5875g은 조리수율·수분손실 미보정 재료합계이며 실측 완성중량이 아님. 기존 식판40g에는 해당 배합을40/65.5875 비례 환산. 기존 계산방식에 따라 춘권피는 탄수화물 기준 곡류군에만 배정하며 제품 자체 지방을 별도 지방군으로 더하지 않음. 게살·치즈 추가 없음, 영양소 탭과 웹사이트는 갱신하지 않음.
